health sync

Google Health → intervals.icu 同期ツール（個人用）

health sync は、Google Health（旧 Fitbit）に記録された自分の 体重・心拍変動（HRV）・安静時心拍数 を読み取り、自分の intervals.icu アカウントの Wellness に書き込む個人用のツールです。

しくみ

開発者本人の GitHub Actions 上で 1 日 2 回実行されます。Google Health API からは読み取り専用のスコープ（googlehealth.health_metrics_and_measurements.readonly）でデータを取得し、intervals.icu の API に書き込みます。一般向けのサービスではなく、利用者は開発者本人だけです。
