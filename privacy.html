health sync ／ 最終更新日: 2026年11月18日

health sync（以下「本ツール」）は、開発者本人が自分のデータを同期するためだけに使う個人用ツールです。本ツールにおける Google ユーザーデータの取り扱いを以下に定めます。

1. 取得するデータ

Google Health API から、次の情報を読み取り専用のスコープ（https://www.googleapis.com/auth/googlehealth.health_metrics_and_measurements.readonly）で取得します。

  • 体重（計測値と計測日時）
  • 日ごとの心拍変動（HRV）
  • 日ごとの安静時心拍数

上記以外のデータ（氏名、連絡先、位置情報など）は取得しません。

2. 利用目的

取得したデータは、利用者本人の intervals.icu アカウントの Wellness 記録に書き込むためだけに使います。広告、分析、機械学習モデルの学習、その他の目的には使用しません。

3. 保存

本ツールは GitHub Actions 上で一時的に実行され、取得したデータを独自のデータベースやファイルに保存しません。データは実行中のメモリ上でのみ扱われ、intervals.icu に送信された後に破棄されます。実行ログには同期した日付と値が記録されることがあり、ログはリポジトリの所有者だけが閲覧できるよう管理します。

4. 第三者への提供

取得したデータは、利用者本人が指定した intervals.icu 以外の第三者に提供、販売、共有しません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. アクセスの取り消し

本ツールに許可したアクセスは、Google アカウントのサードパーティ アクセスの管理ページからいつでも取り消せます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub リポジトリの Issues からお願いします。
